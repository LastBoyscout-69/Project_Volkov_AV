1. Введение

1.1. Что это за программа

SchoolPlanner — десктопное приложение для составления школьного расписания. Программа автоматически распределяет уроки по дням недели с учётом множества ограничений: занятости учителей, кабинетов, методических дней, нагрузки по классам.

1.2. Для кого

  • Завучи — для составления расписания на четверть или год.
  • Директора — для контроля нагрузки.
  • Учителя — для просмотра своего расписания.

1.3. Ключевые возможности

  • 📅 Автоматическое составление расписания — на базе OR-Tools CP-SAT (5 дней × 8 уроков = 40 слотов).
  • 👩‍🏫 Учителя — ФИО, предметы, запрещённые слоты с причинами.
  • 🏫 Классы — название, количество учеников.
  • 📚 Предметы — часы по каждому классу.
  • 🚪 Кабинеты — вместимость, специализированные кабинеты.
  • 🚫 Запрещённые слоты — учитель не может вести урок в это время.
  • 🔁 Замены учителей — поиск замены прямо из ячейки урока. НОВОЕ в v2.2.1
  • 🔍 Умный советчик — подсказывает, что не так до составления.
  • ✏️ Редактирование расписания — клик по уроку → клик по клетке.
  • 🎨 Цветные ячейки — каждый предмет своим цветом.
  • ✅ Проверка накладок кабинетов — после составления показывает детали конфликтов. НОВОЕ в v2.2.1
  • 📥 Импорт из Excel — загрузка данных из template.xlsx.
  • 📊 Экспорт в Excel — все данные и расписание в один файл .xlsx.
  • 🧙 Мастер расписания — 7 шагов с автоматическими проверками.
  • 🔑 Демо-версия — до 5 классов бесплатно, полная — по ключу.

1.4. Системные требования

  • ОС: Windows 10/11 (64-бит)
  • ОЗУ: 4 ГБ
  • Интернет: не требуется
  • Установка: не требуется (один .exe)

Python — удобный, кроссплатформенный, много библиотек.

4. Как работает программа

4.1. Общий поток

1. ЗАПУСК      → Проверка лицензии, инициализация БД
2. ЗАПОЛНЕНИЕ  → Учителя, классы, предметы, кабинеты
                 (вручную или импортом из Excel)
3. АНАЛИЗ      → advisor.py ищет проблемы
4. РЕШЕНИЕ     → scheduler.py (OR-Tools CP-SAT)
5. ПРОВЕРКА    → проверка накладок кабинетов
6. РЕЗУЛЬТАТ   → Расписание на экране
7. ЗАМЕНЫ      → поиск замены для урока (при необходимости)
8. ЭКСПОРТ     → Excel

4.2. Подробно по шагам

Шаг 1. Запуск
Программа проверяет license.py — есть ли ключ активации. Если есть — полная версия. Если нет — демо (баннер, ограничение 5 классов). Создаётся/открывается база school.db.

Шаг 2. Заполнение данных
Пользователь вводит: учителей, классы, предметы, кабинеты. Данные сохраняются в SQLite автоматически. Альтернатива — импорт из Excel (Мастер → Шаг 6 → «📥 Импорт из Excel»).

Шаг 3. Анализ (advisor.py)
Программа проверяет: есть ли учителя у каждого предмета, не превышает ли нагрузка класса 40 часов, хватает ли кабинетов по вместимости, не перегружены ли учителя.

Шаг 4. Решение (scheduler.py)
OR-Tools строит модель. Ограничения: 1 класс — 1 урок, 1 учитель — 1 урок, не более 2 уроков одного предмета в день для класса. Запреты: unavailable_slots. Лимит времени: 10 секунд. Обычно 2–5 секунд.

Шаг 5. Проверка накладок кабинетов НОВОЕ в v2.2.1
После составления программа проверяет, не попали ли два класса в один кабинет в одно время. Если накладок нет — зелёная плашка «Кабинеты в порядке». Если есть — красная плашка с количеством и списком деталей (день, урок, кабинет, класс).

Шаг 6. Результат
Расписание по классам и по учителям. Каждый предмет цветной. Можно кликнуть и переместить (клик по уроку → клик по клетке).

Шаг 7. Замены НОВОЕ в v2.2.1
В ячейке урока есть иконка 🔁 (справа от кабинета). Нажмите — откроется список кандидатов: учителя, которые ведут этот предмет, свободны в этом слоте, не заблокированы. Показывается нагрузка и пометка «уже в классе». Нажмите «Назначить» — имя учителя обновится в ячейке.

Шаг 8. Экспорт (excel_export.py)
Кнопка «📊 Экспорт в Excel» → создаёт .xlsx. Вкладки: расписание по каждому классу, по учителям, списки учителей/классов/предметов/кабинетов.

5. Ключевые алгоритмы

5.1. Решатель расписания (OR-Tools CP-SAT)

Задача: распределить N уроков по 5 дням × 8 слотам (40 слотов) без конфликтов.

Модель:

  • Переменные: x[lesson][day][slot] = 0 или 1
  • Ограничения:
    • sum(x[lesson][*][*]) == 1
    • Для каждого класса/дня/слота: сумма ≤ 1
    • Для каждого учителя/дня/слота: сумма ≤ 1
    • Для каждого класса/предмета/дня: сумма ≤ 2
    • Запрещённые слоты: x = 0
  • Кабинеты распределяются после решения (жадно, с приоритетом специализированных).

Решение: CP-SAT перебирает умно, отсекая невозможные варианты.

Время: обычно 1–5 секунд, лимит — 10 секунд.

5.2. Умный советчик (advisor.py)

Проверки:

  1. Есть ли учителя у всех предметов с часами?
  2. Не превышает ли нагрузка класса 40 часов (5 дней × 8 уроков)?
  3. Хватает ли кабинетов по вместимости для каждого класса?
  4. Не превышает ли нагрузка учителя доступные слоты (40 минус запрещённые)?

Вывод: список проблем с рекомендациями (error / warning / info).

5.3. Поиск замен (substitutions.py) НОВОЕ в v2.2.1

Критерии кандидата:

  1. Ведёт этот предмет (есть в списке subjects).
  2. Свободен в этом слоте (нет своего урока).
  3. Слот не в unavailable_slots.
  4. Не ведёт уже урок в этом классе в этот день (пометка «уже в классе», не блокирует).

Ранжирование: по нагрузке (меньше — лучше) и штрафу за «уже в классе».

Ограничение: замены хранятся в памяти и сбрасываются после перезапуска программы.

6. Лицензия

6.1. Демо-версия

  • Ограничение: не более 5 классов.
  • Баннер сверху с предложением активации.
  • Кнопка «🔑 Ввести ключ».

6.2. Активация

  • Ключ формата SP-XXXX-XXXX-XXXX.
  • Проверяется офлайн по алгоритму md5(соль + номер).
  • Сохраняется в %APPDATA%\SchoolPlanner\license.json и %LOCALAPPDATA%.
  • При обновлении программы — ключ не теряется.

6.3. Генерация ключей

  • keygen.py — только у разработчика.
  • Генерирует ключи по номерам.
  • Не публикуется в открытых источниках.

7. Сборка и запуск

7.1. Запуск из исходников

pip install -r requirements.txt
python desktop_app.py

7.2. Сборка в .exe

flet pack desktop_app.py --name "SchoolPlanner_v2.2.1" ^
  --add-data "advisor.py;." ^
  --add-data "excel_export.py;." ^
  --add-data "excel_import.py;." ^
  --add-data "excel_template.py;." ^
  --add-data "substitutions.py;." ^
  --add-data "storage.py;." ^
  --add-data "database.py;." ^
  --add-binary "C:\Windows\System32\msvcp140.dll;." ^
  --add-binary "C:\Windows\System32\vcruntime140.dll;." ^
  --add-binary "C:\Windows\System32\vcruntime140_1.dll;." ^
  -- --hidden-import ortools --collect-all ortools

7.3. Что получается

Папка dist/SchoolPlanner_v2.2.1/. Внутри .exe и все зависимости. Можно передать пользователю — работает без Python.

7.4. Что приложить к релизу

  • SchoolPlanner_v2.2.1.exe
  • template.xlsx (обязательно рядом с .exe)

Ключевые достоинства:

  • Скорость — OR-Tools решает за секунды.
  • Простота — понятный интерфейс и мастер из 7 шагов.
  • Надёжность — умный советчик предупреждает проблемы, проверка кабинетов ловит накладки.

Проект готов к использованию в реальных школах и может развиваться дальше.
