==========================================================
   SchoolPlanner v2.2.1 — генератор школьного расписания
==========================================================

КАК ЗАПУСТИТЬ
-------------
1. Положите SchoolPlanner_v2.2.1.exe и template.xlsx
   В ОДНУ ПАПКУ (без template.xlsx не работает импорт).
2. Запустите SchoolPlanner_v2.2.1.exe двойным кликом.
3. Первый запуск может занять 5–15 секунд.

Если Windows показывает синее окно «Windows защитила
ваш компьютер»:
    • Нажмите «Подробнее»
    • Затем «Выполнить в любом случае»


ЧТО ДЕЛАТЬ, ЕСЛИ НЕ ЗАПУСКАЕТСЯ
--------------------------------
Ошибка про msvcp140.dll или vcruntime140.dll?
Установите Visual C++ Redistributable:
    https://aka.ms/vs/17/release/vc_redist.x64.exe


КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Вкладка «Учителя» — добавьте учителей и предметы.
2. Вкладка «Классы» — добавьте классы.
3. Вкладка «Предметы» — задайте часы по классам.
4. Вкладка «Кабинеты» — добавьте кабинеты.
5. Вкладка «Расписание» — нажмите «🚀 Составить».

Быстрее — через «🧙 Мастер»: 7 шагов с проверками,
на шаге 6 можно нажать «📥 Импорт из Excel» и загрузить
данные из template.xlsx.


ЧТО НОВОГО в v2.2.1
-------------------
• 🔁 Замены учителей — иконка 🔁 в ячейке урока.
• ✅ Проверка накладок кабинетов — зелёная/красная плашка
  после составления, с деталями конфликтов.


ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
school.db — база данных (SQLite), создаётся рядом с .exe.
Можно скопировать на другой компьютер для переноса данных.


ДЕМО-ВЕРСИЯ
-----------
• До 5 классов.
• Ключ активации: SP-XXXX-XXXX-XXXX.
• Вводится один раз, сохраняется в системе.


ЧАСТЫЕ ПРОБЛЕМЫ
---------------
1. «Не удалось составить расписание»
   → Откройте «Мастер» — он подскажет проблему.

2. «Импорт не сработал»
   → Проверьте, что template.xlsx лежит рядом с .exe.

3. «Замены пропали после перезапуска»
   → В v2.2.1 замены хранятся в памяти. Сохраните
     расписание в Excel перед закрытием.

4. «Красная плашка “Накладки в кабинетах”»
   → Два класса попали в один кабинет. Проверьте
     список деталей и добавьте кабинеты.
